Research & Writing

cbomctl — post-quantum policy conflict analysis

Open-source tool that reads a CycloneDX Cryptographic Bill of Materials and evaluates it against seven national post-quantum policies at once, reporting where their requirements contradict each other. Every rule cites the section or page it was read from, names who verified it, and records whether the source is a draft.

The finding that came out of reading all seven primary documents: the authorities are not disagreeing about cryptography. Germany, France and the EU recommend hybrid key establishment; Australia recommends against it while granting the same premise; the NSA does not permit it on national security systems. It is a disagreement about which failure mode is likelier, not about the mathematics.

Agent-ready codebases

A documented method for making a large codebase legible to AI coding agents: one conventions file read by every tool, skills written for the flows a single file cannot explain, and a routing table so the right one is loaded before the agent starts guessing. Published with the numbers from two comparable work windows and an explicit account of what those numbers do not prove.
